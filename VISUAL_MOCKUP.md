## Interaction Flow

### 1. Initial Load
```
User opens app
    ↓
Navigate to /interactive-map
    ↓
Map displays with all markers
    ↓
Default zoom: 100%
```

### 2. Zoom Interaction
```
User pinches screen
    ↓
Zoom level changes (0.1x - 4.0x)
    ↓
Zoom indicator updates
    ↓
Markers scale appropriately
```

### 3. Pan Interaction
```
User drags screen
    ↓
Map pans in drag direction
    ↓
Markers maintain positions
```

### 4. Marker Tap
```
User taps trainer marker
    ↓
Bottom sheet slides up
    ↓
Shows trainer details
    ↓
User can dismiss or tap outside
```

### 5. Filter Toggle
```
User taps filter chip
    ↓
Marker visibility toggles
    ↓
Map updates immediately
    ↓
Chip appearance updates
```

## Performance Characteristics

```
Marker Count:  ~160 total (40 trainers + 100 items + 20 portal groups)
Render Method: Stack with Positioned widgets + CustomPainter
Frame Rate:    60 FPS (on typical mobile device)
Memory Usage:  ~50MB (including base image)
Zoom Range:    0.1x to 4.0x (40x range)
Pan Speed:     1:1 with finger movement
```

```
✓ Semantic labels on all markers
✓ Text descriptions in bottom sheets  
✓ Button controls for zoom (not gesture-only)
✓ High contrast colors (WCAG AA compliant)
✓ Touch targets: 48x48 dp minimum
✓ Screen reader support via Material widgets
```
